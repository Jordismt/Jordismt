## 🤖 Resbix — Plataforma SaaS de agentes de IA

**Node.js · Express · Vue.js · Supabase · PostgreSQL · Groq · Stripe · Upstash Redis**

Resbix es una plataforma SaaS que permite a los negocios automatizar la atención al cliente mediante agentes conversacionales de inteligencia artificial.

El objetivo es que los negocios puedan atender consultas, gestionar reservas y centralizar la información de sus clientes desde una única plataforma.

### Funcionalidades

- Agentes conversacionales configurables para cada negocio.
- Configuración del tono, saludo e instrucciones del agente.
- Integración de IA mediante Groq.
- Gestión de reservas y disponibilidad.
- Panel de administración para negocios.
- Gestión de clientes y conversaciones.
- Arquitectura multiempresa.
- Autenticación mediante Supabase.
- Políticas de seguridad RLS.
- Integración de pagos y suscripciones con Stripe.
- Integración de Upstash Redis.
- Landing pages configurables con asistente integrado.

### Desarrollo técnico

He desarrollado tanto el frontend como el backend, trabajando en la arquitectura de la aplicación, las APIs REST, la lógica de negocio, las integraciones externas y la gestión de datos.

Este proyecto me ha permitido profundizar en el desarrollo de aplicaciones SaaS, arquitecturas multiempresa e integración de inteligencia artificial.

## 🍽️ Carteliax — SaaS de cartas digitales para restaurantes

**Vue.js · Node.js · Express · Supabase · PostgreSQL · Stripe**

Carteliax es una plataforma SaaS para que restaurantes y establecimientos gastronómicos puedan crear y administrar sus propias cartas digitales.

Los negocios pueden actualizar sus productos desde un panel de administración sin necesidad de modificar su página web.

### Funcionalidades

- Registro y gestión de negocios.
- Creación de múltiples cartas por restaurante.
- Gestión de categorías y productos.
- Información de alérgenos.
- Subida de logotipos e imágenes de productos.
- Generación de cartas digitales accesibles mediante QR.
- Gestión de disponibilidad de productos.
- Autenticación y aislamiento de datos por negocio.
- Integración de suscripciones mediante Stripe.
- Diseño responsive.

### Desarrollo técnico

Desarrollo de una aplicación SaaS con gestión de usuarios, almacenamiento de imágenes, base de datos PostgreSQL y políticas RLS mediante Supabase.

El proyecto está orientado a proporcionar una herramienta sencilla para que los restaurantes administren sus cartas digitales.

## 🎙️ PresuVoz — Generador de presupuestos con IA

**Nuxt · Vue.js · Supabase · Groq · Whisper · Stripe · Vercel**

Plataforma SaaS diseñada para profesionales autónomos que necesitan crear presupuestos de forma rápida.

Permite transformar descripciones de voz o texto en presupuestos editables utilizando inteligencia artificial.

### Funcionalidades

- Generación de presupuestos mediante voz o texto.
- Transcripción de audio.
- Interpretación de conceptos mediante inteligencia artificial.
- Edición de presupuestos.
- Exportación a PDF.
- Historial de presupuestos.
- Configuración de datos fiscales.
- Autenticación de usuarios.
- Sistema de créditos y suscripciones.
- Integración de pagos con Stripe.

Este proyecto combina desarrollo web, procesamiento de lenguaje natural e integración de servicios externos.
